# 中間テスト対策ノート v1.1

中1・二学期中間テストに向けた、授業内容に基づく暫定学習アプリです。学推 Exam Boost v5.4 の教科カード、学習モード、解説、手書き、学習分析の構成を参考にしました。

## 最初の使い方

1. `index.html` をブラウザで開くか、GitHub Pagesで公開したURLを開きます。
2. 教科を選び「練習を始める」を押します。
3. 入力・選択問題は自動採点。証明や説明問題は、入力または手書き後に解答例・基準と照合します。
4. 「学習分析」で入力・選択と自己確認の結果を分けて確認できます。
5. 正式な範囲表が届いたら「範囲・データ」で各単元を「範囲確定」または「範囲外」に変更します。

テスト日は推測で設定していません。設定するとホームに残り日数を表示します。

## 学習モード

- 今日の10問：1問ごとの結果を次の出題に反映。用意した固定問題が10種類未満の場合はその数で終了します。
- 単元別：対象を選んで練習。
- 苦手集中：直近の誤答・自己確認・未診断を使って優先度を計算。
- まとめ演習：対象単元から最大20問。任意で15・20・30分の目安時間を設定。学校の模試を再現するモードではありません。
- 学習分析：正答数、回答数、経験した問題型、最近の記録を表示。習得率や本番予測得点は表示しません。

## 収録範囲

114種類の問題型を収録。うち8種類は数学の数値生成型で、他は固定問題です。同じセッション内で固定問題を繰り返しません。数値生成型は同じ型から複数問が出ることがあります。

- 英語：疑問詞、Which、所有表現、Whose、命令文・呼びかけ、be/一般動詞、三単現、短文英作文。
- 数学：文字式、一次方程式、数量・等式・不等式、単位、合同条件、基本証明。
- 国語：返り点・書き下し、置き字・再読文字の基礎復習、五段・下一段の名称確認。
- 理科：音・振動、波形比較、震源・震央、P/S波の基本、プレート・断層、弾性・弾性力。
- 社会：ASEAN、旧石器・縄文・弥生の生活変化・遺跡・伝来、古代中国の前提復習。

国語の学校本文・漢字指定範囲、生物・化学系、技術・家庭科などは資料待ちです。範囲の設定だけでは未収録問題は追加されません。学校の出題比率・試験時間・全範囲の網羅は未確定です。9月28日の授業情報は学校での学習確認であり、正式な中間範囲の確定ではありません。

## 採点と記録

- 方程式は `x=3` の形が必要です。`3` や `3=x` は学校の答案形式に合わせて不正解になります。
- 文字式は、かっこ・分数・小数を含む同値な多項式を照合します。分数は縦型で表示します。入力は `(3x+1)/2` の形も使えます。
- 英文は大文字小文字、末尾の句読点、余分な空白を許容します。登録した別解以外は認識できない場合があります。
- 判定に疑問がある場合は「別解・判定を保留」で正答率と苦手判定から除外できます。
- 手書きの自動文字認識はありません。手書き画像は履歴に保存しません。
- 記述は基準ごとのチェックで自己確認します。機械採点と混同しません。
- 途中で閉じても採点済みの記録は保存されます。未完了のセッションそのものは再開されません。
- 保存先はブラウザのlocalStorageです。同じURLでも端末・ブラウザが違えば別記録です。
- 「全記録を書き出す」でJSONバックアップを取得し、別端末で取り込めます。バックアップ取り込みは履歴を置き換えるため、事前確認画面を表示します。
- 個人の過去の答案や誤答履歴を公開用ソースへ埋め込んでいません。アプリ内の新しい解答で診断を始めます。

## プロジェクトとの情報受け渡し

科目プロジェクトの文章は、開発時に人が確認して問題・単元データへ反映します。公開アプリからChatGPTや各プロジェクトを自動で読み込む機能はありません。

「範囲・データ」の取り込みで扱うのは、このアプリのバックアップJSONと、次の範囲設定JSONです。

```json
{
  "schemaVersion": 1,
  "kind": "midterm-plan",
  "examDate": "",
  "ranges": {
    "en_wh": {"status": "confirmed", "note": "範囲表で確認"},
    "ma_eq": {"status": "confirmed", "note": "範囲表で確認"}
  }
}
```

`status` は `candidate`（候補）、`confirmed`（確定）、`prerequisite`（前提復習）、`excluded`（範囲外）、`waiting`（資料待ち）。単元IDは `bank.js` に記載。

## GitHub Pagesへの公開

新しいリポジトリ（例：`midterm-study-2026`）を作り、このフォルダのファイルを同じ階層でアップロードします。Settings → Pagesで、Deploy from a branch → main → / (root) を選びます。ビルドやAPIキーは不要です。

学推アプリとは別のリポジトリにすることを想定しています。個人のバックアップJSONをリポジトリへアップロードしないでください。

## ファイル

- `index.html`：入口
- `style.css`：スマートフォン・タブレット対応の画面
- `core.js`：数式採点、正規化、出題優先度
- `bank.js`：単元と問題データ、SVG図
- `app.js`：画面、学習モード、保存、範囲設定、取り込み
- `manifest.webmanifest`・アイコン：ホーム画面表示用
- `VALIDATION.md`：検証結果と未実施事項

外部CDN・AI APIへの依存はありません。Service Workerは使っていないため、明示的なオフライン保証はありません。

## 地図の出典

東南アジアの地図はNatural Earth（Public Domain）の国境データをworld-atlas 2.0.2経由で利用し、学習用の表示範囲へ投影しています。位置のラベルは首都を示しません。
