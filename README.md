# 中間対策ノート v2.0.5 — 2026-10-11

9試験（英語・代数・幾何・国語3・国語2・理科Ⅰ・理科Ⅱ・地理・歴史）に対応する静的Webアプリ。

## 使い方

ZIPを展開し、index.htmlをブラウザで開きます。安定した記録保存には同じ公開URL・同じブラウザを使ってください。端末を移す前に「記録・設定」から全記録を書き出し、移動先でJSONを読み込みます。保存はブラウザ内で、クラウド同期やサーバーへの解答送信はありません。

GitHub Pagesでは、このフォルダ内のファイルを公開フォルダへ置きます。ビルドや外部ライブラリの取得は不要です。

## 更新内容

- 固定900問、数値・条件を変える57生成型、74技能。社会は地理210問・歴史160問。
- 正式範囲、学校で扱ったか、教材掲載、実際の習得度を区別。
- 科目別演習、未診断、実際の誤答中心の復習、実戦、地図、記述、推定・関連復習。
- 数学は一次方程式利用・指数法則・比・角度・合同条件・回転体・球を重点化。
- 理科は追加資料の英単語21語、力、ばね、波形、地震計算、火山・岩石・鉱物を反映。
- 国語は活用を日常復習に分離。具体的な漢文12文、現代文の観点、漢字43字の読み書き、ページ別チェックを追加。
- 同じ回では同じ問題を繰り返さず、誤答は間隔を置いた別問題や次回の復習に反映。国語の習得度は0〜3、他は0〜4。
- 旧版の解答履歴を保持して移行。教師や他チャットの参考評価は実解答ログと分離。

## 採点

選択・入力は正答との照合。方程式は原則x=数、単位指定は単位を含めます。手書きと記述は採点基準による自己確認で、AI自動採点ではありません。許容表現に合わない正答は「保留」にし、誤答集計から外せます。

## 重要な除外

幾何の合同証明・相似・三平方、関数の比例反比例、二次方程式、高校指数は中間演習から除外。国語の活用種類・活用形は日常復習専用。英語L6 SceneとL5/L6 Readは本文読解に使いません。歴史No.15〜16の推定補完は別枠。理科の震源深さ計算は学校資料で確認されており、幾何の三平方除外とは別に扱います。

## 資料待ち

- 国語：語句60〜90頁、獅子と鼠の古文・訳の対応、漢字全語句とページ対応、文法の教材そのままの設問、漢文の指定読みと対象プリントの照合。
- 社会：学校白地図の番号位置最終照合、歴史No.14の同一性とNo.15〜16原本、指定地形一覧。
- 英語：範囲内の全語句と全設問。数学：推定しているプリントの個別問題・図。
- 理科：地層・堆積岩・化石の個別範囲対応。

確認済みの項目から作ったオリジナル問題です。学校教材の全設問を再現・網羅したアプリではありません。図は練習用模式図で、教材写真そのものではありません。
